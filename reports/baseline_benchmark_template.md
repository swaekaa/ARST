## Training Commands

```bash
# Sanity baselines (non-trainable)
python train.py model=majority
python train.py model=random

# Learned baselines (full multimodal)
python train.py model=mlp
python train.py model=cnn
python train.py model=lstm
python train.py model=transformer

# Unimodal ablations (IMU example)
python train.py model=mlp model.active_modalities=[imu]
python train.py model=transformer model.active_modalities=[imu]

# Quick debug (50k rows, 3 epochs)
python train.py model=mlp data.max_rows=50000 training.epochs=3

# With W&B tracking
python train.py model=transformer wandb.enabled=true
```
